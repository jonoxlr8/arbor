# Ask Arbor + Learn (local review)

Ask Arbor is a bounded explanation layer. `/chat` authenticates the owner, classifies a question, and calls existing deterministic profile, portfolio, monthly, goal, and projection services only where needed. General education uses static reviewed templates without loading an owner profile or portfolio. No LLM, order execution, trade selection, or provider ranking is added. Client requests contain only the question; owner identity comes from verified authentication.

Chat messages and draft are current-session React state, not durable conversation history. Switching Chat/Learn preserves the mounted conversation. Suggestions and a lesson's **Ask Arbor about this** action fill an editable composer draft; neither sends a request nor consumes usage. The user explicitly sends it. A failed request keeps the draft and shows a retryable error. Authenticated users still completing onboarding can open the same Chat/Learn view for general education, without a saved plan. Raw questions and financial values are not intentionally logged.

Learn is a static, version-controlled 12-lesson registry in `frontend/lib/learnLessons.ts`. Lessons have stable IDs, one category, sections, sources, a reviewed date, and an Ask draft. Reading is Free. Links are HTTPS and open with `noopener noreferrer`. No arbitrary HTML or remote page content is rendered. The Arbor workflow lesson describes product behavior and cites the application itself; other lessons cite primary education/regulatory sources, principally [Investor.gov](https://www.investor.gov/introduction-investing) and [BSP UITF rules](https://www.bsp.gov.ph/Regulations/MORB/2021MORNBFI.pdf). Review provider-specific or time-sensitive facts against official materials before changing content; never fetch them live per chat question.

The existing private beta grants Plus Trial. Basic owner portfolio value and goal progress, when complete, are distinct from Plus allocation, monthly and future-value explanations. Free simulation remains local/account-scoped. The deferred public Free Ask usage migration and ten-per-UTC-month policy are **not activated** here; do not treat this local UI as public quota launch. Existing successful-answer metering is left in place for later public rollout.

Future integration: expand factual provider comparisons from reviewed official data, add durable history only after a separate privacy/storage decision, and qualify all chat categories with broader owner-scoped fixtures. This change does not modify plan weights, portfolio valuation, dated ledger, market data, reminders, or primary navigation.
