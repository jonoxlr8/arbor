The September 26 premium pass replaces active investment/provider marks with
original Arbor vectors. These files remain unchanged historical assets; the
source/permission notes below no longer describe active UI selection.
See `docs/INVESTMENT_IDENTITY.md` for the current presentation system.

`pdax.png`, `bpi.png`, `atram.png`, `dragonfi.png`, `gotrade.png` and `gcash.png`,

records filenames, sizes and SHA-256 hashes; tests verify them. Original artwork
has not been recolored, redrawn, cropped or altered. Next.js delivers small
responsive versions without changing the identity design.

including Vanguard, Coins.ph and PDAX. GFunds/GCrypto share GCash artwork while
retaining their own visible names. No trademark permission, partnership,
endorsement or copyright exemption is asserted. User submission is provenance,
not proof of a license. Earlier permission findings are retained below for
owner review before publication; they have not been waived by this update.
