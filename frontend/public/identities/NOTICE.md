# Bitcoin symbol attribution

This notice applies to the retained historical `bitcoin.svg` file only. The
active UI now uses the separately owner-supplied PNG described in
`../brands/NOTICE.md`; no license for that replacement is inferred here.

Source: Bitcoin Design, “The visual language of bitcoin”
https://bitcoin.design/guide/getting-started/visual-language/

Original downloadable SVG:
https://bitcoin.design/assets/images/guide/getting-started/visual-language/bitcoin-symbol.svg

The Bitcoin Design project's license explicitly permits images in its assets
directory to be reused under Creative Commons Attribution 4.0 International:
https://bitcoin.design/LICENSE
https://creativecommons.org/licenses/by/4.0/

The guide credits the orange, tilted symbol's design to bitboy (2010).
Arbor uses the supplied artwork without visual alteration. Only SVG comments,
unused definitions and whitespace were removed. No endorsement is implied.

Text tiles are used only as loading/unknown-identity fallbacks. Corporate
artwork and its provenance are documented separately in `../brands/NOTICE.md`.
